# AstiMira VisionStack

Отдельное Android-приложение для экспериментов с **многослойной обработкой видео с фронтальной камеры**. У него собственный GitHub-репозиторий, пакет `lt.astimira.visionstack` и отдельная сборка APK. В нём нет кода, рекламы, ключей или функций LifePilot / OopsPlan.

## Что можно проверить

- Живое зеркальное видео передней камеры, без отправки кадров на сервер.
- Ввод SPH / CYL / AXIS **по каждому глазу**. Рецепт задаёт только **начальные приблизительные** параметры; это не точная оптическая модель глаза.
- Два независимых GPU-слоя направленной предварительной обработки: вдоль выбранной оси и перпендикулярно ей.
- Радиус слоёв, тонкая подстройка оси, общий и локальный контраст, гамма, осветление, размер лица.
- Отдельные автоматически сохраняемые настройки для правого и левого глаза и кнопка сброса.

**Важно:** возможность имитировать астигматизм не означает, что размытие можно точно обратить с помощью обычного дисплея. Эта версия — исследовательский прототип для субъективной проверки на телефоне, **не заменяет очки, диагностику или лечение**. Слишком сильные настройки дают ореолы и могут ухудшить видимость.

## Скачать на Android

Откройте **Releases → AstiMira VisionStack Android test → Assets → AstiMira-VisionStack-debug.apk**.

Если релиза пока нет, откройте вкладку **Actions → Build AstiMira Android APK**, дождитесь зелёной галочки. APK публикуется в отдельном тестовом GitHub Release, а не в Actions Artifacts (там может не хватать свободного места).

Установите APK на Android, разрешите использование камеры. Попробуйте без очков и при хорошем освещении настроить сначала два независимых слоя, затем контраст. Изображение станет хуже — нажмите «Сбросить фильтры».

## Собрать локально

Откройте **именно этот репозиторий** в Android Studio с JDK 17. Требуется Android SDK 35.

Команда (если установлен Gradle 8.11.1):

```sh
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

**Только этот самостоятельный проект:** workflow собирает приложение из корня текущего репозитория и публикует APK в собственных Releases.
